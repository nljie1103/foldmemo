保存与安全

打开时要求密码

默认开启。关闭该选项前必须先关闭加密；在未加密模式下，密码校验仅限制页面操作，并不能保护磁盘上的明文数据。

加密存储

默认开启：AES-256-GCM 加密浏览器缓存、数据文件与 HTML 内嵌资料。关闭后文件和缓存均为明文，导入密码无法提供真正的安全保护。

文件保存方式

浏览器自动缓存始终启用；这里选择额外绑定的数据文件格式。加密与否由上方开关决定。

正式保存与绑定文件

未绑定文件。首次点击「保存到文件」选择位置。

文件导入

支持 v0.0.1、v0.0.2 加密备份、v0.0.3 数据文件或单文件 HTML。加密文件必须输入正确主密码。

导出折叠 Markdown

Markdown 为明文格式。可选择包含或省略密码类字段；包含敏感信息时请勿上传公开仓库。

修改主密码

修改后会更新浏览器缓存。之前导出的加密文件仍使用旧密码，请另存新副本。

锁定工作台

清除页面内已解锁的记录与密钥，下一次使用按安全设置重新打开。

此应用未经独立安全审计。浏览器缓存可能被清除，本地文件绑定权限也可能失效；请保存多份独立备份。
