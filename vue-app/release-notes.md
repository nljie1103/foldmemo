# FoldMemo v2.0.3 · 文件授权与在线预览只读保护

- 创建保险库后立即显示文件授权提示，首次写入成功之前严格禁止新增和编辑分类、记录、笔记、主题及密码。
- 解锁后若原文件写入权限未恢复，则以只读模式打开，并提供明显的恢复授权入口。
- 已授权的 Chrome/Edge 本地文件继续自动写回当前 HTML，权限丢失时停止编辑并要求重新授权。
- KodBox/可道云的沙盒在线预览只读，不错误地把本机选中的文件当作服务器原文件；提供下载本地 HTML 的指引。
- 保留 v2.0.2 的保险库数据格式和加密方式，不引入云端授权令牌或上传密码。

测试边界：云端可道云 HTML 不能凭纯前端代码直接覆盖服务器文件，需要专用授权后端或本地同步客户端。
