### 主要变更

- 重构保险库数据密钥与打开密码封装机制，减轻重复加密开销。
- 避免浏览器草稿静默覆盖当前 HTML 数据，恢复旧草稿必须由用户主动确认。
- 添加文件绑定保险库 ID、源码形状和写入摘要校验，防止意外覆盖其他文件。
- 对损坏保险库添加恢复提示，禁止直接当作空库初始化。
- 加入回收站、保存状态和拖拽手柄、键盘排序。
- 增加加解密、篡改、身份与连续保存的自动测试。

### 运行与构建

Release 附件是 `index.html`；源码及测试保存在 Git 仓库 `vue-app/`。

### 安全注意事项

加密与文件格式有较大变化。请保留旧版加密备份，先用虚构记录测试锁定、导入、保存和重新打开。未经安全审计，不建议作为重要密码唯一备份。

- 修正 HTML 内嵌保险库接口的 TypeScript 类型兼容：同时支持 v2 `FilePackage<Vault>` 和既有 Vue 备份格式，不改变实际加密算法。
