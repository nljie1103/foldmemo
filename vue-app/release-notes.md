# FoldMemo v2.0.2 · 修复笔记分类选择和筛选

- 新建与编辑长文本笔记现在同样显示「所属分类」下拉框，可选择已有分类，不会再在保存时将分类 ID 清空。
- 新笔记优先预选当前分类筛选项；无分类时仍允许先保存笔记。
- 在「笔记与记录」新增「未分类笔记」筛选入口，历史版本产生的无分类笔记仍可找到，并可以编辑后重新归类。
- 简洁风三列便签、普通卡片与笔记详情中均显示正确分类名称。
- 两种内容类型共享已有分类，不改变分类字段模板，也不修改既有保险库加密格式。
- 加强分类引用校验：已分类的笔记必须引用存在的分类，避免幽灵分类。
- 新增测试：笔记归类、切换筛选、旧笔记恢复归类、无效分类拒绝；保留主题、Proxy 和加密回归测试。

## 兼容性与安全

v2.0.2 兼容 v2.0.1 的 `foldmemo-file-2` 保险库格式，不主动迁移、删除或改写既有记录。历史无分类笔记仅在用户编辑并保存时才更改所属分类。构建成功并不代表浏览器存储已完成验收，使用真实账号信息前请验证 HTML 写回与重开流程。
