# FoldMemo v2.0.1 · 三套主题设计复原

- 系统主题独立主侧栏入口、内置垂直分组侧栏，设置页面只管理密码与文件。
- 默认风格对照 v1.0.4 的布局尺寸、玻璃层、留白、边框、阴影、色板与导航行为；不变动保险库结构和加密格式。
- 简洁风对照 Daniel Rozhnov 的 Note Desk 1440px 设计稿：浅灰侧栏、四块快捷入口、三列极简便签与仅编辑时出现的顶部工作标签。原设计未提供公开组件源码，属视觉复现，不宣称使用原作者程序。
- 现代风对照用户提供的 AppDown Admin 2.0 Vue HTML 源码的 New York/Linear 设计体系，包括固定 244px 导航、工作区选择器、顶部面包屑、深浅主题和全局语义色板。
- 保留 v2.0.0 的加密、导入、文件绑定、回收站等处理，不更换数据格式。
- 需 Windows 端执行 Vue typecheck / Vite 构建及真实浏览器交互验收；当前环境无法访问 npm 注册表，不提供未经编译的正式 HTML。
