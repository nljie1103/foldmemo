### 主要变更

- 首次引入 Vue 3、TypeScript、Vite 单文件构建和 shadcn-vue 源码组件。
- 将表单、记录、设置和主题状态迁入 Vue 响应式应用。
- 默认、简洁、现代三种主题保留在新的工作台中。
- 移除首页悬浮加号，将简洁风分类导航调整到内容区域。

### 运行与构建

Release 附件为可离线打开的 `index.html`；项目源码位于 Git 仓库 `vue-app/`。
构建需 Node.js、npm，并在首次安装时获取 Vue 与 shadcn-vue 依赖。
